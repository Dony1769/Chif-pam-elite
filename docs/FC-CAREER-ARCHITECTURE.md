## 🐛 ÉTAPE 2 — CORRECTION DES BUGS CRITIQUES

> **Objectif** : Le jeu doit être stable avant d'ajouter du contenu.
> **Terminé quand** : Chaque bug ci-dessous est corrigé et testé.

### 2.1 — Bugs à Corriger

| # | Bug | Gravité | Correction Attendue |
|---|-----|---------|---------------------|
| B1 | Barre d'entraînement repart à zéro après rechargement de page | 🔴 Critique | La progression est sauvegardée dans `localStorage` à chaque tick. Au rechargement, elle reprend là où elle était. |
| B2 | Un entraînement peut être comptabilisé plusieurs fois | 🔴 Critique | Un flag `sessionCompleted` empêche le double comptage. L'action du jour est verrouillée après exécution. |
| B3 | Un match repris après crash ne restaure pas l'état correct | 🟠 Majeur | L'état du match est sauvegardé à chaque événement. La reprise recharge l'état exact. |
| B4 | Actions interdites non bloquées côté logique (ex: jouer 2 matchs le même jour) | 🟠 Majeur | Le `GameEngine` valide chaque action avant exécution. Les règles métier sont appliquées côté moteur, pas seulement côté UI. |
| B5 | Pas d'export/import de sauvegarde | 🟡 Mineur | Bouton « Exporter sauvegarde » (JSON) et « Importer » dans les paramètres. |
| B6 | Pas de confirmation avant actions irréversibles | 🟡 Mineur | Modal de confirmation pour : accepter transfert, changer de club, prendre sa retraite. |

### 2.2 — Critères de Validation

```
✅ Recharger la page pendant un entraînement → la barre reprend
✅ Cliquer 10x sur "Entraîner" → 1 seule session comptée
✅ Fermer le jeu pendant un match → reprise correcte
✅ Essayer de jouer 2 matchs le même jour → refusé par le moteur
✅ Exporter → Importer → état identique
```

## 🎓 ÉTAPE 3 — ACADÉMIE → PRO

> **Objectif** : Parcours réaliste du centre de formation aux professionnels.
> **Terminé quand** : Un joueur U17 ne peut PAS jouer en équipe première. La promotion est conditionnelle.

### 3.1 — Niveaux du Centre de Formation

| Niveau | Âge | Matchs/Saison | Contre qui | Accès Équipe Supérieure |
|--------|-----|---------------|-----------|------------------------|
| **U17** | 14-16 | 20-25 | Autres académies U17 | → U19 si rating ≥ 55 + avis coach |
| **U19** | 16-18 | 25-30 | Autres académies U19 | → Réserve si rating ≥ 62 + avis coach |
| **Réserve** | 17-21 | 30-34 | Clubs de D3/National | → Pros si rating ≥ 68 + appel du coach principal |
| **Équipe Première** | 17+ | 34-50+ | Élite Gallia + Coupes | Titulaire si rating ≥ 72-78 (selon club) |

### 3.2 — Règles Strictes

```
RÈGLE D'OR : Un joueur d'académie NE PEUT PAS jouer en senior.

Exceptions contrôlées :
- Le coach principal peut "appeler" un joueur de Réserve pour UN match
  → Seulement si 3+ blessés au même poste
  → Le joueur retourne en Réserve après le match
  → Pas plus de 3 appels par saison sans promotion officielle

Promotion officielle :
- Évaluation en fin de saison (ou mi-saison exceptionnellement)
- Critères : Rating minimum + Nombre de matchs joués + Note moyenne ≥ 6.5
- Le coach propose la promotion → le joueur accepte (auto)
- Une fois promu, pas de retour au niveau inférieur (sauf prêt en réserve)
```

### 3.3 — Vie en Académie

```
Quotidien U17-U19 :
- 5 entraînements / semaine (obligatoires)
- 1 match / semaine (week-end)
- Cours scolaires (événement aléatoire : "examen raté → moral -5")
- Pas de salaire, juste une bourse (50-200€/mois)
- Pas d'agent autorisé avant 16 ans
- Logement au centre de formation

Quotidien Réserve :
- 5 entraînements / semaine
- 1-2 matchs / semaine
- Premier contrat stagiaire possible (500-2000€/mois)
- Agent autorisé
- Peut être observé par des clubs étrangers
```

### 3.4 — Évaluation et Notation Académie

## 📊 ÉTAPE 4 — ATTRIBUTS, ÂGE & POTENTIEL

> **Objectif** : Système d'attributs ultra-réaliste avec courbe d'âge, potentiel caché, forme et moral.
> **Terminé quand** : Un joueur de 33 ans décline physiquement. Le potentiel s'épuise. La forme varie.

### 4.1 — Les 51 Attributs

```
PHYSIQUE (7) :
  Vitesse | Force | Endurance | Accélération |
  Vitesse de Sprint | Agilité | Équilibre

TECHNIQUE (12) :
  Dribble | Centre | Passe | Précision Passe Courte |
  Précision Centre | Puissance Frappe | Finition |
  Tir Lointain | Effet | Volée | Contrôle Balle | Pied Faible

MENTAL (15) :
  Positionnement | Sang-Froid | Prise de Décision | Temps de Réaction |
  Vision de Jeu | Conscience | Concentration | Détente Verticale |
  Précision Tête | Sens Défensif | Discipline Tactique |
  Jeu Hors-Balle | Intensité | Leadership | Personnalité

DÉFENSE (12) :
  Marquage | Tacle | Positionnement Défensif | Tacle Glissé |
  Tacle Debout | Interception | Jeu de Tête Défensif |
  Contres | Dégagements | Agressivité | Anticipation | Force Bras (GK)

GARDIEN (5) :
  Plongeon | Prise de Balle | Jeu au Pied | Placement (GK) | Réflexes
```

### 4.2 — Courbe d'Âge Réaliste

```
Âge 14-17 : Croissance rapide     → Gains entraînement x1.5
Âge 18-21 : Croissance forte      → Gains entraînement x1.3
Âge 22-24 : Pic de croissance     → Gains entraînement x1.0
Âge 25-28 : Prime (plateau)       → Gains entraînement x0.7 (maintien)
Âge 29-31 : Début déclin          → Gains x0.3, Physique -1/saison
Âge 32-34 : Déclin marqué         → Gains x0.1, Physique -2/saison, Mental stable
Âge 35+   : Déclin fort           → Physique -3/saison, Technique -1/saison

Exceptions :
- Un joueur avec "Longévité" (trait caché) décline 2 ans plus tard
- Un joueur blessé gravement peut décliner prématurément
```

### 4.3 — Potentiel Caché

```typescript
type HiddenPotential = {
  maxRating: number           // 70-99, jamais révélé directement au joueur
  growthRate: number          // 0.5-2.0 (vitesse de progression)
  ceilingReached: boolean     // true quand rating actuel ≥ maxRating - 2
  
  // Le joueur voit seulement :
  // ⭐ "Potentiel limité" (max 74)
  // ⭐⭐ "Bon potentiel" (max 79)
  // ⭐⭐⭐ "Très bon potentiel" (max 84)
  // ⭐⭐⭐⭐ "Potentiel exceptionnel" (max 89)
  // ⭐⭐⭐⭐⭐ "Potentiel de classe mondiale" (max 94+)
}
```

### 4.4 — Forme & Moral

```
FORME (0-100) :
  - Affecte les performances en match (-15% si forme < 30)
  - Descend avec la fatigue, les blessures, le manque de jeu
  - Monte avec les entraînements, les matchs joués, le repos
  - Un joueur en mauvaise forme (<30) a +20% risque de blessure

MORAL (0-100) :
  - Affecte la progression d'entraînement (+10% si moral > 80, -10% si < 30)
  - Monte : victoires, titularisation, but/passe décisive, compliment coach, nouveau contrat
  - Descend : défaites, banc, critique médias, blessure, conflit avec coach
  - Moral < 20 → le joueur peut demander un transfert
  - Moral > 90 → bonus de performance en match (+0.3 rating)

FATIGUE (0-100, 100 = épuisé) :
  - Match joué entier : +25 fatigue
  - Match remplaçant (30 min) : +10 fatigue
  - Entraînement normal : +15 fatigue
  - Entraînement intensif : +22 fatigue
  - Repos actif : -25 fatigue
  - Repos complet : -40 fatigue
  - Jour sans activité : -10 fatigue
  - Fatigue > 80 → performances match -20%, risque blessure x2
```

> **Objectif** : Entraînements réalistes avec progression sauvegardée.
> **Terminé quand** : La barre de progression persiste après rechargement. Les gains respectent le potentiel.

### 5.1 — Types de Sessions

| Session | Attributs Ciblés | Gain | Fatigue | Disponibilité |
|---------|-----------------|------|---------|---------------|
| **Équilibré** | Tous | +0.5 à +1.5 | +15 | Toujours |
| **Vitesse** | Vitesse, Accél., Sprint | +2 à +4 | +20 | 2x/semaine max |
| **Technique** | Dribble, Passe, Contrôle | +2 à +4 | +18 | 2x/semaine max |
| **Défense** | Marquage, Tacle, Positionnement | +2 à +4 | +18 | 2x/semaine max |
| **Finition** | Finition, Frappe, Effet | +2 à +4 | +20 | 2x/semaine max |
| **Mental** | Vision, Décision, Concentration | +1 à +3 | +12 | 3x/semaine max |
| **Gardien** | Plongeon, Réflexes, Placement | +2 à +4 | +18 | Gardiens uniquement |
| **Repos Actif** | Aucun | 0 | -25 | Toujours |
| **Repos Complet** | Aucun | 0 | -40 | Toujours |

### 5.2 — Facteurs de Progression

```
Gain réel = Gain base × Facteur Âge × Facteur Fatigue × Facteur Potentiel × Facteur Moral

Facteur Âge     : voir courbe 4.2
Facteur Fatigue : 1.0 si fatigue < 40, 0.7 si 40-70, 0.3 si > 70
Facteur Potentiel : 1.0 si loin du plafond, 0.1 si plafond atteint
Facteur Moral   : 1.1 si moral > 80, 1.0 si 40-80, 0.85 si < 40
Facteur Coach   : 1.0 (normal), 1.15 (bon coach), 1.3 (coach d'élite)
```

## 🪑 ÉTAPE 7 — CONCURRENCE, BANC & OBJECTIFS

> **Objectif** : Le joueur n'est pas toujours titulaire. Il doit mériter sa place.
> **Terminé quand** : Le coach peut mettre le joueur sur le banc. Les objectifs de saison existent.

### 7.1 — Hiérarchie au Poste

```
Chaque club a un effectif de 25 joueurs (simulés, avec ratings).
À chaque poste, il y a 2-3 joueurs en concurrence.

Le coach choisit le titulaire selon :
  1. Rating au poste (50% du choix)
  2. Forme actuelle (20%)
  3. Fatigue (15%)
  4. Performances récentes — 3 derniers matchs (15%)

Résultat possible pour le joueur :
  - TITULAIRE : joue 90 min (sauf substitution)
  - REMPLAÇANT : peut entrer en jeu (60e-75e min) si le coach décide
  - TRIBUNE : ne joue pas du tout (si rating trop bas ou blessé)
```

### 7.2 — Objectifs du Coach

```
En début de saison, le coach fixe des objectifs au joueur :

Exemples :
  - "Je veux que tu joues 20 matchs cette saison"
  - "Tu dois marquer au moins 8 buts"
  - "Maintiens une note moyenne de 7.0"
  - "Pas plus de 4 cartons jaunes"

Réussite :
  - Objectifs atteints → Moral +15, confiance coach +20
  - Objectifs ratés → Moral -10, risque de banc, pas de prolongation

Objectifs varient selon :
  - Position du joueur (attaquant = buts, défenseur = clean sheets)
  - Rating du joueur (meilleur = objectifs plus élevés)
  - Ambition du club (gros club = exigences fortes)
```

### 7.3 — Système de Prêt

```
Si le joueur est trop faible pour le club actuel :
  - Le coach propose un prêt (6 mois ou 1 saison)
  - Club de prêt = club de division inférieure ou club étranger moyen
  - Avantages : plus de temps de jeu, progression plus rapide
  - Inconvénient : pas de compétitions majeures

Le joueur peut :
  - Accepter le prêt → part au club de prêt
  - Refuser → reste mais risque la tribune
  - Demander un prêt → si le coach accepte

Fin de prêt :
  - Retour au club parent
  - Si bon prêt (rating +5 ou plus) → chance de devenir titulaire
  - Si mauvais prêt → nouveau prêt ou transfert définitif proposé
```

## ⚽ ÉTAPE 8 — MATCHS & NOTATION

> **Objectif** : Matchs avec des choix tactiques et une notation détaillée post-match.
> **Terminé quand** : Le joueur fait des choix qui affectent sa note. Les stats sont complètes.

### 8.1 — Déroulement du Match

```
PRÉ-MATCH :
  - Voir la composition (titulaire / remplaçant / tribune)
  - Voir l'adversaire (rating, forme, classement)
  - Voir les conditions (domicile/extérieur, météo, importance)

PENDANT LE MATCH (simulation temps réel 2-3 min) :
  Le joueur ne contrôle PAS les actions. Le moteur simule.
  Mais le joueur voit tout en temps réel :
  - Chrono 0'-90'+ (avec temps additionnel)
  - Score qui évolue
  - Événements : buts, passes décisives, cartons, tirs, arrêts
  - Sa note qui monte/descend en live
  - Ses stats individuelles en temps réel

MOMENTS DE CHOIX (3-5 par match, apparaissent à des moments clés) :
  - "Corner : tu te places au 1er poteau (agressif) ou au 2e (prudent) ?"
  - "Tu dribbles ton adversaire (risqué) ou tu passes (sûr) ?"
  - "Tu tires de loin (30% réussite) ou tu avances (50% mais risque perte) ?"
  - "Tu contestes la décision de l'arbitre (risque carton) ou tu acceptes ?"
  
  → Le choix affecte directement les événements qui suivent
  → Choix risqué réussi = +0.5 note, raté = -0.3 note
```

### 8.2 — Notation Détaillée (0.0 - 10.0)

```
Note de base : 6.0

Bonus :
  +1.5  But marqué
  +1.0  Passe décisive
  +0.5  Tir cadré
  +0.3  Passe clé (occasion créée)
  +0.3  Interception réussie
  +0.2  Tacle réussi
  +0.2  Dribble réussi
  +0.5  Clean sheet (défenseurs/gardien)
  +0.3  Arrêt (gardien)
  +0.2  Duel aérien gagné

Malus :
  -1.5  Erreur menant à un but adverse
  -0.5  Pénalty concédé
  -0.3  Perte de balle dangereuse
  -0.2  Passe ratée (moins de 70% de passes réussies)
  -0.5  Carton jaune
  -2.0  Carton rouge
  -0.3  Dribble raté
  -0.2  Tir hors cadre

Note finale plafonnée : [3.0 - 10.0]
Homme du match : note la plus haute de l'équipe (≥ 7.5 requis)
```

### 8.3 — Types de Matchs et Enjeux

```
AMICAL :        Impact faible sur la carrière, bon pour la forme
CHAMPIONNAT :   Impact standard, affecte le classement et les stats
COUPE :         Impact élevé, match unique (pas droit à l'erreur)
EUROPA :        Impact très élevé, visibilité internationale
CHAMPIONS :     Impact maximum, le monde regarde
SÉLECTION :     Impact sur la carrière internationale (voir Étape 13)
```

## 🤝 ÉTAPE 9 — AGENTS, CONTRATS & MERCATO

> **Objectif** : Système d'agents réaliste avec 3 profils, contrats détaillés et fenêtres de mercato.
> **Terminé quand** : Le joueur a un agent. Les transferts ne se font qu'en été et en hiver.

### 9.1 — Système d'Agents (3 Profils)

| Agent | Style | Commission | Forces | Faiblesses |
|-------|-------|-----------|--------|------------|
| **Le Prudent** | Sécurité d'abord | 5% | Contrats longs et stables, bons bonus de fidélité | Peu ambitieux, offres moyennes |
| **L'Ambitieux** | Vise le top | 10% | Négocie les meilleurs salaires, clubs prestigieux | Peut forcer un transfert, pression constante |
| **Le Requin** | Maximum d'argent | 15% | Sponsors lucratifs, primes énormes | Commission élevée, peut ruiner les relations avec le club |

### 9.2 — Relation avec l'Agent

```
Le joueur choisit un agent à 16 ans (ou au premier contrat pro).
L'agent peut être changé, mais :
  - Pénalité de rupture de contrat (10% du salaire annuel)
  - 6 mois sans agent (pas de négociation possible)
  - Le nouvel agent peut refuser si la réputation du joueur est mauvaise

L'agent fait :
  - Négocier les contrats (salaire, durée, clauses)
  - Trouver des clubs intéressés
  - Négocier les sponsors
  - Donner des conseils (parfois mauvais selon le profil)
  - Prendre sa commission sur chaque contrat et prime
```

### 9.3 — Contrats Détaillés

```typescript
type Contract = {
  club: string
  salary: number              // €/mois
  duration: number            // en saisons (1-5)
  signingBonus: number        // prime de signature
  releaseClause: number | null // clause libératoire (optionnel)
  
  performanceBonuses: {
    perGoal: number
    perAssist: number
    perCleanSheet: number
    perMatch: number
    leagueTitle: number
    cupWin: number
    championsLeague: number
  }
  
  loyaltyBonus: number        // prime si le joueur reste jusqu'au bout
  agentFee: number            // % commission agent
  
  status: 'active' | 'expiring' | 'expired'
  yearsRemaining: number
}
```

### 9.4 — Fenêtres de Mercato

```
MERCATO D'ÉTÉ : 1er juin - 31 août
  - Fenêtre principale
  - Tous les transferts possibles
  - Le joueur reçoit des offres si : rating > 70 + bonne saison
  - Le joueur peut demander à partir (si clause ou fin de contrat proche)

MERCATO D'HIVER : 1er - 31 janvier
  - Fenêtre secondaire
  - Transferts plus rares et plus chers
  - Surtout des prêts
  - Joueurs mécontents (banc, moral bas) plus susceptibles de partir

HORS MERCATO :
  - AUCUN transfert possible
  - Le joueur peut négocier une prolongation avec son club actuel
  - Les clubs peuvent approcher le joueur en fin de contrat (6 derniers mois)
  - Joueurs libres peuvent signer à tout moment
```

## 💰 ÉTAPE 10 — ÉCONOMIE, SPONSORS & VIE PRIVÉE

> **Objectif** : Gestion financière réaliste et événements de vie privée.
> **Terminé quand** : Le joueur gagne, dépense et vit comme un vrai footballeur.

### 10.1 — Revenus

```
SALAIRE : selon contrat (500€ - 500 000€/mois selon le club et le niveau)
  - Académie : 50-200€/mois (bourse)
  - Stagiaire pro : 500-2 000€/mois
  - Pro D2 : 2 000-10 000€/mois
  - Pro D1 (petit club) : 5 000-30 000€/mois
  - Pro D1 (gros club) : 30 000-200 000€/mois
  - Star mondiale : 200 000-500 000€/mois

PRIMES : selon contrat
  - Match joué : 500-5 000€
  - But : 1 000-10 000€
  - Passe décisive : 500-5 000€
  - Homme du match : 2 000-15 000€
  - Clean sheet : 1 000-8 000€
  - Titre championnat : 50 000-500 000€
  - Coupe : 20 000-200 000€
  - Coupe des Champions : 100 000-1 000 000€

SPONSORS :
  - Débloqués quand rating > 75 + 15 matchs joués en D1
  - Petit sponsor (local) : 1 000-5 000€/mois
  - Sponsor moyen (national) : 5 000-20 000€/mois
  - Grand sponsor (international) : 20 000-100 000€/mois (rating > 85)
  - Les sponsors partent si la forme/les résultats baissent
```

### 10.2 — Dépenses & Style de Vie

```
DÉPENSES OBLIGATOIRES :
  - Impôts : 30-45% du revenu brut
  - Commission agent : 5-15% (selon agent choisi)
  - Logement : adapté au salaire (500-10 000€/mois)

DÉPENSES OPTIONNELLES (choix du joueur, affectent le moral et l'image) :
  - Voiture : Économique (0€) → Luxe (5 000€/mois)
  - Style de vie : Simple (0€) → Extravagant (10 000€/mois)
  - Dons caritatifs : 0-5% du salaire → améliore l'image publique
  - Investissements : 0-20% du salaire → revenus passifs à la retraite

CONSÉQUENCES :
  - Vie extravagante + mauvais résultats = critiques médias, moral -10
  - Vie simple + bons résultats = image "travailleur", sponsors fidèles
  - Faillite possible si dépenses > revenus pendant 6 mois
```

### 10.3 — Vie Privée (Événements Aléatoires)

```
Événements positifs :
  - Naissance d'un enfant → Moral +20
  - Mariage → Moral +15, stabilité +10
  - Achat maison → Dépense ponctuelle, confort +5

Événements négatifs :
  - Scandale médiatique → Image -20, sponsors menacés
  - Problème familial → Moral -15 pendant 2 semaines
  - Cambriolage → Perte financière, moral -10

Événements neutres :
  - Interview TV → choix de réponses → impact sur image
  - Invitation gala → +image si accepté, neutre si refusé
  - Proposition pub → revenu + risque d'image
```

## 📰 ÉTAPE 11 — MÉDIAS, ÉVÉNEMENTS, BLESSURES & SANCTIONS

> **Objectif** : Le monde réagit aux performances du joueur. Les blessures et sanctions existent.
> **Terminé quand** : Les médias commentent, les blessures surviennent, les cartons s'accumulent.

### 11.1 — Système Médiatique

```
Après chaque match, les médias réagissent :

PRESSE :
  - Note < 5.0 → "Prestation catastrophique de [Joueur]"
  - Note 5.0-6.0 → "Match discret pour [Joueur]"
  - Note 6.0-7.0 → "Performance correcte"
  - Note 7.0-8.0 → "Très bon match de [Joueur]"
  - Note 8.0-9.0 → "Performance exceptionnelle !"
  - Note 9.0+ → "[Joueur] a été MAGISTRAL"

RÉSEAUX SOCIAUX (fictifs) :
  - Nombre de followers augmente avec les performances
  - Commentaires positifs/négatifs selon les résultats
  - Buzz si but spectaculaire ou erreur grossière

CONFÉRENCES DE PRESSE (événements ponctuels) :
  - Le joueur doit répondre à 2-3 questions
  - Choix de réponses → impact sur image et relations
  - Exemples : "Que pensez-vous de votre concurrent au poste ?"
    → "Il est bon, ça me motive" (diplomate, +image)
    → "Je suis meilleur que lui" (arrogant, -image mais +confiance)
    → "Pas de commentaire" (neutre)
```

### 11.2 — Blessures

```
RISQUE DE BLESSURE par match :
  - Base : 3% par match
  - Fatigue > 70 : risque x2 (6%)
  - Fatigue > 90 : risque x3 (9%)
  - Forme < 30 : risque +2%
  - Terrain mauvais : risque +1%
  - Match intense (coupe, derby) : risque +1%

TYPES DE BLESSURES :
| Blessure | Durée | Fréquence | Impact |
|----------|-------|-----------|--------|
| Contusion | 1-3 jours | 35% | Fatigue +10 |
| Élongation | 1-2 semaines | 25% | Physique temp. -5 |
| Entorse | 2-4 semaines | 15% | Physique temp. -8 |
| Déchirure musculaire | 4-8 semaines | 10% | Physique temp. -10 |
| Fracture | 2-4 mois | 8% | Rating temp. -5 |
| Ligaments croisés | 6-9 mois | 5% | Rating perm. -2 à -5 |
| Blessure chronique | Récurrente | 2% | Risque +3% permanent |

RÉÉDUCATION :
  - Pendant la blessure : pas de match, pas d'entraînement normal
  - Entraînement de rééducation disponible (récupération accélérée)
  - Rechute possible (10%) si retour trop rapide
```

### 11.3 — Sanctions Disciplinaires

```
CARTONS :
  - Jaune : avertissement, 3e jaune en 10 matchs = 1 match de suspension
  - 2e jaune dans un match = rouge = expulsion
  - Rouge direct : 1-3 matchs de suspension

ACCUMULATION :
  - 5 jaunes en saison → 1 match de suspension
  - 10 jaunes en saison → 2 matchs de suspension
  - 3 rouges en saison → audition disciplinaire → 3-5 matchs

COMPORTEMENT HORS TERRAIN :
  - Retard à l'entraînement → amende (1 jour de salaire)
  - Conflit avec le coach → banc pendant 2-3 matchs
  - Scandale public → suspension interne + amende
```

```
Le joueur peut être :

Pour être nominé :

```

### 12.2 — Récompenses de Saison

```
MEILLEUR BUTEUR DE L'ÉLITE :

MEILLEUR PASSEUR DE L'ÉLITE :

MEILLEUR JOUEUR DE L'ÉLITE :

JOUEUR DU MOIS :

ÉQUIPE TYPE DE LA SAISON :
```

## 🏁 ÉTAPE 14 — RETRAITE, HÉRITAGE & FINS

> **Objectif** : Plusieurs fins possibles selon la carrière vécue.
> **Terminé quand** : Le joueur peut prendre sa retraite. Un score d'héritage est calculé. Plusieurs fins existent.

### 14.1 — Déclencheurs de Retraite

```
RETRAITE VOLONTAIRE :
  - Disponible à partir de 32 ans
  - Le joueur choisit de se retirer
  - Match d'adieu (si club le veut) → événement spécial

RETRAITE FORCÉE :
  - Blessure grave récurrente (3+ blessures longues)
  - Rating tombé sous 60 et aucun club ne veut du joueur
  - Âge > 38 (automatique, sauf exception)

CARRIÈRE BRISÉE :
  - Accumulation de sanctions → exclusion définitive
  - Scandale majeur → fin de carrière anticipée
  - Faillite financière + aucun club → retraite forcée dans l'ombre
```

### 14.2 — Score d'Héritage (0-100)

```
Le score est calculé à la retraite et résume TOUTE la carrière :

TROPHÉES (max 35 points) :
  - Championnat national : +5/titre (max 25)
  - Coupe Nationale : +3/titre
  - Coupe des Champions : +8/titre
  - Coupe d'Europa : +4/titre
  - Coupe du Monde : +10 (max 1)
  - Championnat d'Europa : +7 (max 1)

STATISTIQUES (max 25 points) :
  - 100+ buts en carrière : +5
  - 200+ buts : +10
  - 300+ buts : +15
  - 50+ passes décisives : +3
  - 100+ sélections nationales : +7
  - Note moyenne carrière > 7.5 : +5

RÉCOMPENSES INDIVIDUELLES (max 25 points) :
  - Globe d'Or : +8/trophée (max 24)
  - Meilleur Buteur : +3/titre
  - Meilleur Joueur : +3/titre
  - Soulier d'Or : +4/titre
  - Équipe Type : +1/sélection (max 5)

PARCOURS (max 15 points) :
  - Joué dans 3+ championnats différents : +3
  - Capitaine d'un club : +2
  - Capitaine de la sélection : +5
  - Fidélité (10+ ans dans un club) : +5
  - Du centre de formation au pro dans le même club : +3
```

### 14.3 — Les Fins Possibles

| Score | Titre | Description |
|-------|-------|-------------|
| **90-100** | 🏛️ **LÉGENDE VIVANTE** | Ton nom est gravé dans l'histoire. Statue devant le stade. Légende incontestable. |
| **75-89** | ⭐ **ICÔNE DU FOOTBALL** | Carrière exceptionnelle. Respecté par tous. Consultant TV ou futur entraîneur. |
| **60-74** | 🎖️ **CARRIÈRE SOLIDE** | Tu as bien vécu du football. Pas une légende, mais un professionnel respecté. |
| **40-59** | 📋 **JOUEUR MOYEN** | Carrière correcte sans éclat. Peu de gens se souviennent de toi. Reconversion difficile. |
| **20-39** | 😔 **POTENTIEL GÂCHÉ** | Tu aurais pu faire mieux. Blessures, mauvais choix ou manque de travail ont freiné ta carrière. |
| **0-19** | 💀 **CARRIÈRE BRISÉE** | Scandales, sanctions ou faillite ont détruit ta carrière. Ton nom est associé à l'échec. |

### 14.4 — Écran de Fin

```
Animation finale :
  1. Montage des meilleurs moments (buts, trophées, sélections)
  2. Statistiques complètes de carrière (scroll infini)
```
